# Tech Stack

## Frontend
- **Framework**: React 18
- **Build Tool**: Vite 5
- **Language**: TypeScript
- **Styling**: Vanilla CSS (CSS Variables)
- **Maps Integration**: Leaflet (`leaflet`, `react-leaflet`)
- **Routing**: React Router (`react-router-dom`)
- **Internationalization**: i18next (`i18next`, `react-i18next`)
- **Components**: `rc-slider` for range inputs

## Backend
- **Environment**: Node.js
- **Framework**: Express.js
- **Language**: JavaScript (ES Modules)
- **Database Adapters**: `pg` (PostgreSQL), `sql.js` (SQLite)
- **Authentication**: `jsonwebtoken`, `bcrypt`
- **Security Middleware**: `helmet`, `cors`, `express-rate-limit`
- **Validation**: `express-validator`
- **Utilities**: `uuid`, `ical-generator`

## Infrastructure
- **Frontend Hosting**: Vercel
- **Backend Hosting**: Render
- **Database Hosting**: Neon.tech (PostgreSQL)
